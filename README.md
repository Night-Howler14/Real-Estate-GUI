Real Estate Management System (GUI)
Overview
This project is a comprehensive Real Estate Management System designed with a graphical user interface (GUI) using Python's Tkinter library. The system is intended to streamline real estate operations by providing an efficient way for both real estate agents and office staff to manage and report property transactions.

Features
1. Office Interface
The office interface provides the following functionalities for real estate office staff:

Sales Reports: Generate detailed reports for each agent, including sale dates, property details, and selling prices.
Rental Reports: View comprehensive information on properties rented by each agent, including rental amounts, areas, and dates.
2. Agent Interface
The agent interface allows real estate agents to:

Update Database: Record new property sales or rentals directly into the database.
Project Structure
The project is organized into three main folders:

DB: Contains the database files used in the project. Ensure to load these files into your local host to use the system.
Code: Houses the Python code for the Tkinter-based GUI.
Image: Includes visual assets utilized within the project.
Installation and Setup
Database Setup: Import the database files from the DB folder into your local database environment.
Run the Application: Execute the Python scripts located in the Code folder to launch the GUI application.
Assets: The Image folder contains the necessary visuals. Ensure these files are correctly referenced in your code.
Requirements
Python 3.x
Tkinter
SQLite (or relevant database engine used)
Usage
Agent Interface: Use this to update property sales and rental records.
